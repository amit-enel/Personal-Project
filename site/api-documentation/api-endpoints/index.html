    API Endpoints

    Get All Charging Stations

    GET /stations

    Description

    Fetches a list of all charging stations.

    Request

    GET /stations

    Response (200 OK)

    [
  {
    "createdAt": "2026-10-19T08:30:15.457Z",
    "stationName": "Mumbai Central EV Hub",
    "location": "Mumbai",
    "status": "Available",
    "connectorCount": 8,
    "id": "1"
  }
]

    Get Single Charging Station

    GET /stations/{id}

    Description

    Fetches a specific charging station by ID.

    Path Parameters

    Parameter Type Required Description
    id string Yes Charging station ID

    Request

    GET /stations/1

    Response (200 OK)

    {
  "createdAt": "2026-10-19T08:30:15.457Z",
  "stationName": "Mumbai Central EV Hub",
  "location": "Mumbai",
  "status": "Available",
  "connectorCount": 8,
  "id": "1"
}

    Create Charging Station

    POST /stations

    Description

    Creates a new charging station record.

    Request Body

    {
  "stationName": "Pune EV Plaza",
  "location": "Pune",
  "status": "Available",
  "connectorCount": 6
}

    Response (201 Created)

    {
  "createdAt": "2026-10-19T12:15:36.686Z",
  "stationName": "Pune EV Plaza",
  "location": "Pune",
  "status": "Available",
  "connectorCount": 6,
  "id": "41"
}

    Update Charging Station (Full Update)

    PUT /stations/{id}

    Description

    Replaces the entire charging station record.

    Request

    PUT /stations/41

    Request Body

    {
  "stationName": "Pune Smart Charging Hub",
  "location": "Pune",
  "status": "Busy",
  "connectorCount": 10
}

    Response (200 OK)

    {
  "createdAt": "2026-10-19T12:15:36.686Z",
  "stationName": "Pune Smart Charging Hub",
  "location": "Pune",
  "status": "Busy",
  "connectorCount": 10,
  "id": "41"
}
